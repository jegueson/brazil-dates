# Link Building — Calendário Brasileiro

Ações manuais recomendadas após o deploy do conteúdo:

## 1. API JSON open source (GitHub)

- Publicar repositório `calendario-feriados-api` com os arquivos de `public/api/feriados/*.json`.
- Licença MIT ou CC BY 4.0 com atribuição obrigatória.
- README com exemplos em JavaScript e Python.

## 2. Widget embedável

- Divulgar `/widget` em comunidades de devs e blogs de RH.
- Cada embed gera link `calendario-feriados.com.br` no iframe.

## 3. HARO / Conexão Jornalista

- Cadastrar-se em serviços de relação com imprensa BR.
- Responder pedidos sobre "datas comemorativas" e "feriados 2026".

## 4. Parcerias RH e viagem

- Contatar editores de artigos sazonais (Catho, Vagas, Melhores Destinos).
- Oferecer calendário como fonte citável com link.

## 5. Wikipedia

- Adicionar referências ao site em artigos de feriados **somente** onde o conteúdo for neutro e verificável.
- Evitar spam — edições são revertidas.

## 6. Google Discover (Web Stories)

- Criar Web Stories para Carnaval, Festa Junina e Natal (ferramenta do Google).
- Linkar para guias `/feriado/*`.

## Meta

- 50+ domínios referenciando em 12 semanas
- 5+ links de DR > 40
